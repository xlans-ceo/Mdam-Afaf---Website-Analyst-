# OWASP ASVS 5.0 Level 1 Compliance Matrix (`docs/ASVS_L1.md`)

Target Standard: **OWASP Application Security Verification Standard (ASVS) 5.0 — Level 1** (Beta target).

## Verification Transparency Note
- The official OWASP ASVS 5.0 restructures the standard into **17 top-level chapters (`V1` through `V17`)**.
- Because full verbatim third-level requirement text from the external OWASP repository cannot be fetched directly inside the isolated build container, this matrix uses the official **ASVS 5.0 chapter IDs (`V1`–`V17`) and section topics** without inventing synthetic sub-requirement numbers.
- Every row is marked **`Pass` ONLY when backed by a verified source file and passing automated test** in this repository. Requirements that depend on production cloud infrastructure or manual browser verification are marked **`NOT VERIFIED`**, and features not used by Madam Afaf (such as WebRTC, OAuth/OIDC, or user password authentication) are marked **`N-A`**.
